# Project Template Structure

This is a reference template showing the correct file layout for FPGA projects in this repo.

## File Structure

```
NN_projectname/          # Folder name with incrementing number
├── projectname.pcf      # Pin constraint file
├── projectname.v        # Verilog module
├── apio.ini            # APIO configuration
├── .gitignore          # Git ignore patterns
└── _build/             # Generated by apio (auto-ignored)
```

## File Contents

### projectname.pcf
- Pin mappings for the ICEStick board
- Defines oscillator (clk), LEDs, and PMOD I/O connections
- Copy from this template and update pin numbers as needed

### projectname.v
- Module stub with input/output signature
- No implementation - just the frame structure
- Update module name to match project name

### apio.ini
- Auto-generated by `apio create -b icestick`
- Must update `top-module` to match the module name in .v file
- Do NOT create manually

### .gitignore
- Ignores _build directory (generated files)
- Ignores .DS_Store (macOS artifacts)

## Usage Notes

1. Copy this entire folder as `NN_projectname/`
2. Rename all files to `projectname`
3. Update module name in .v file
4. Update top-module in apio.ini
5. Implement your logic in the .v file
