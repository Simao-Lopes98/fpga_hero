# FPGA to HERO
Repo to (some day) create a soft core with a RISC-V.

## APIO
Using APIO to build, synth, test and upload.

To install follow [Getting Started](https://fpgawars.github.io/apio/docs/installing-apio-cli/#install-using-a-file-bundle_2)

When installed, to find help, use

```
apio
```
