# AI Verilog Learning Agent - Handover Document

## Project Overview

This is an FPGA learning repository focused on Verilog development using the **ICEStick Evaluation Board**. The repository contains progressive lessons from an introductory FPGA course with working examples.

**Repository Location:** `/root/prjs/fpga_hero/`

## Key Hardware Specifications

### ICEStick Board Details
- **FPGA:** Lattice iCE40HX1K
- **Oscillator:** Discera 12 MHz MEMS oscillator (pin 21)
- **User LEDs:** 5 programmable LEDs (pins 99, 98, 97, 96, 95)
- **PMOD Connectors:** 2x Digilent PMOD compatible connectors for I/O
- **Communication:** FTDI 2232H USB device for programming and UART
- **Flash:** Micron 32Mbit N25Q32 SPI flash

## Creating New Projects - CRITICAL WORKFLOW

### File Structure Reference
Use `ai_OS/template_project/` as the exact reference structure.

Each project must contain:
```
NN_projectname/
├── projectname.pcf       # Pin constraint file
├── projectname.v         # Verilog module
├── apio.ini             # Auto-generated APIO config
├── .gitignore           # Ignore patterns
└── _build/              # Generated by apio (auto-ignored)
```

### Strict Sequential Steps

1. **Create folder** with incrementing number
   - Pattern: `05_projectname`, `06_projectname`, etc.
   - Ask user for project name if not provided

2. **Create .pcf file** (pin constraint file)
   - Filename: `{projectname}.pcf`
   - Copy structure from `ai_OS/template_project/template_project.pcf`
   - Define: oscillator (clk pin 21), LEDs (pins 99-95), PMOD pins

3. **Create .v file** (Verilog module stub)
   - Filename: `{projectname}.v`
   - Module stub only - NO implementation yet
   - Example: `module fsm_moore (input [1:0] pmod, input clk, output reg [4:0] led); endmodule`

4. **Create .gitignore**
   - Copy from `ai_OS/template_project/.gitignore`
   - Should contain: `_build` and `.DS_Store`

5. **DO NOT create apio.ini manually** ⚠️
   - This must be auto-generated by APIO

6. **Run APIO initialization**
   ```bash
   cd {projectfolder}
   apio create -b icestick
   ```
   - This auto-generates apio.ini with `top-module = main`

7. **Edit apio.ini - REQUIRED**
   - Change `top-module = main` to `top-module = {projectname}`
   - This must match the module name in the .v file

### Common Mistakes to Avoid

- ❌ Creating apio.ini manually before running `apio create`
- ❌ Forgetting to update `top-module` in apio.ini
- ❌ Not matching .v module name with apio.ini top-module
- ❌ Adding implementation code in step 3 (should be stub only)

## Important Notes for Agent Operations

1. **Always check current directory before running commands**
   - Use full paths when needed: `cd /root/prjs/fpga_hero/{projectname}`

2. **When creating new projects:**
   - First verify the incrementing number (check what exists)
   - Ask user for project name if not specified
   - Follow the exact 7-step workflow

3. **When referencing examples:**
   - Direct agent to `ai_OS/template_project/` first
   - Then to `03_counter/` for working examples

4. **Oscillator frequency is critical:**
   - 12 MHz is the base clock
   - Projects often divide this down (e.g., to 1 Hz for LEDs)
   - Pin 21 on the board

5. **PCF file management:**
   - Pin numbers are specific to ICEStick board
   - Oscillator: pin 21
   - LEDs: pins 99, 98, 97, 96, 95
   - PMOD: pins typically 78, 79

## Troubleshooting

If `apio create` fails:
- Check that the project folder exists
- Ensure you're in the correct directory
- Verify board is set to `icestick` in apio.ini
- Check file naming consistency

If synthesis fails:
- Verify module name in .v matches top-module in apio.ini
- Check PCF pin assignments are correct for ICEStick
- Ensure all inputs/outputs are properly declared
